# AI Study Notes Generator

An AI-powered web application that converts PDF study materials into concise notes, flashcards, quizzes, and mind maps using Google Gemini AI.

## Features

- 📄 Upload PDF documents
- 📝 Generate AI-powered study notes
- 🧠 Create flashcards
- ❓ Generate quizzes
- 🗺️ Generate mind maps
- 💾 Download generated notes

## Tech Stack

### Backend
- Python
- FastAPI
- Google Gemini API
- PyMuPDF

### Frontend
- React
